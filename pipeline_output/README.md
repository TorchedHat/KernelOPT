# Pipeline Output Directory

This directory stores output files generated by `kernelopt run` during the optimization pipeline.

## Output Structure

When you run the optimization pipeline, the following files are generated:

### Baseline Profiling
- `baseline.csv` - NCU profiling data (CSV format with sections, rules, launch stats)
- `baseline.ncu-rep` - NCU report file (binary format, can be opened with Nsight Compute UI)
- `baseline_profiling_context.json` - Parsed profiling context with metrics

### Optimization Iterations

For each iteration `N` and optimization plan `X` (A, B, C, D):

**Generated Kernels:**
- `{kernel_name}_iter{N}_plan{X}_{plan_description}.py` - Optimized kernel source code

**Profiling Data:**
- `{kernel_name}_iter{N}_plan{X}_{plan_description}.csv` - NCU profiling CSV
- `{kernel_name}_iter{N}_plan{X}_{plan_description}.ncu-rep` - NCU report (binary)
- `{kernel_name}_iter{N}_plan{X}_{plan_description}_profiling_context.json` - Parsed metrics

**Example:**
```
flash_attention_triton_iter1_planA_increase_eligible_warps_per_scheduler.py
flash_attention_triton_iter1_planA_increase_eligible_warps_per_scheduler.csv
flash_attention_triton_iter1_planA_increase_eligible_warps_per_scheduler_profiling_context.json
```

### Pipeline Summary Files
- `best_kernel.py` - The best performing kernel from all iterations
- `optimization_log.md` - Human-readable log of the optimization process
- `optimization_memory.json` - Optimization insights accumulated during the pipeline

## File Formats

### CSV Files (`*.csv`)
NCU sections-based profiling data with three main sections:
- **Sections**: Performance metrics (SM throughput, memory throughput, occupancy, etc.)
- **Rules**: Optimization recommendations from NCU's guided analysis
- **Launch**: Kernel launch configuration (grid size, block size, registers, shared memory)

### Profiling Context JSON (`*_profiling_context.json`)
Structured profiling data including:
```json
{
  "sections": {
    "GPU Speed Of Light Throughput": [...],
    "Occupancy": [...],
    ...
  },
  "rules": [...],
  "launch": {...},
  "kernel_source": "...",
  "kernel_name": "..."
}
```

### NCU Report Files (`*.ncu-rep`)
Binary NCU report files that can be opened with:
```bash
ncu-ui <filename>.ncu-rep
```

## Directory Management

This directory is excluded from git via `.gitignore` to avoid committing large profiling output files.

To clean up old outputs:
```bash
# Remove all generated files except this README
find pipeline_output -type f ! -name 'README.md' -delete
```

## CLI Usage

Specify output directory with `--output-dir`:
```bash
kernelopt run kernel.py --output-dir pipeline_output -T 3 -N 2
```

Default output directory is `./pipeline_output` if not specified.
